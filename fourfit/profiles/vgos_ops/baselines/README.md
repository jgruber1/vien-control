# Fourfit baseline control-file fragments

These files are baseline-specific `.cf` fragments extracted from the supplied `vo6147.cf` control file.

Included baselines:

- `ST.cf`
- `WV.cf`

Each file contains the active ionosphere override, baseline-specific frequency selection, and notch definitions for that baseline.

Recommended target path in `vien-control`:

```text
fourfit/profiles/vgos_ops/baselines/
```
